Maintenance note

Never delete or overwrite a file in downloads/. Microsoft's rule for Store package URLs is that "the binary on the package URL must not change after it is submitted", so every file here must stay byte-identical and reachable forever once its URL has been submitted. Adding a new version means adding a new file (the filenames already carry the version) and updating the "Current" list above — the old entries move to "Previous versions" and stay put.

Each new version also needs an Update submission in Partner Center pointing at the new URL; the Store does not pick up a new version on its own.

Binaries are built by GitHub Actions from the matching tag — see the releases.
